## How to search and confirm the correct ticker?

When buying stocks, it is essential to choose the **primary market** where the company is listed.

**For example, to search for the Hermès ticker (French market):**

- **Ticker:** RMS
- **Market:** EPA - Euronext Paris

![Search Hermès Ticker](/images/M2/D3/ES-M2-D3-Buscar-ticker-hermes.png)

In Interactive Brokers, when searching for the ticker, it appears as being on the **SBF** (Société des Bourses Françaises) market, the former name of Euronext.

> **Note:** SBF and EPA are equivalent; IBKR has not yet updated the denomination.

![IBKR Ticker RMS - Hermes](/images/EN/M2/D3/EN-M2-D3-IBKR-Ticker-Hermes.png)

Here is an official guide (created by IBKR) on market equivalences:

- https://gdcdyn.interactivebrokers.com/en/trading/order-type-exchanges.php?ot=loc

![IBKR Market Guide](/images/M2/D3/ES-M2-D3-Guia-mercados.png)

## How to set up the watchlist?

Watchlists are useful for organizing tickers of interest and avoiding errors.

**I recommend creating at least:**

- **Main list:** Base or core stocks of the portfolio.
- **Gray list:** Secondary or potentially interesting companies.

### To create a list

1. Go to **Research -> Watchlist**

![IBKR Watchlist](/images/EN/M2/D3/EN-M2-D3-Watchlist.png)

2. Click on **"New Watchlist"**.

![IBKR Create new watchlist](/images/EN/M2/D3/EN-M2-D3-Create-new-watchlist.png)

Assign a name and add the desired tickers, for example:

- **Watchlist name:** Core companies
- **Ticker:** GOOGL

![IBKR Configure new watchlist](/images/EN/M2/D3/EN-M2-D3-Create-new-watchlist-part2.png)

3. Select the financial product (stocks, options, warrants).

![IBKR Configure new watchlist part 2](/images/EN/M2/D3/EN-M2-D3-Create-new-watchlist-part3.png)

4. **Save the list**

![IBKR Save new watchlist](/images/EN/M2/D3/EN-M2-D3-Save-new-watchlist.png)

Immediately after pressing the save button, we will see that the list has been created in the main panel and we can select it.

![IBKR Watchlist created](/images/EN/M2/D3/EN-M2-D3-New-Watchlist-pillar-companies.png)

### To add or remove symbols

- Click on the **three horizontal dots** to access configuration options.
- You can rename, add/edit symbols, edit columns or delete the list.

![IBKR Watchlist add or remove](/images/EN/M2/D3/EN-M2-D3-Watchlist-Add-Remove.png)

### To buy from the watchlist

- Click on the **three vertical dots** next to the ticker and select the buy option.
- You can also access a chart and other options from the financial instrument.

![IBKR Watchlist buy](/images/EN/M2/D3/EN-M2-D3-Watchlist-Buy-Sell.png)
