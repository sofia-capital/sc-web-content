Before buying stocks, check the currency in which they are listed. Exchanging currency in advance allows you to control the process and get a better price.

There are two ways to do it:

### 1st - First method

1. From **Portfolio -> Positions**
2. Click on the currency you want to exchange

![IBKR Currency exchange from Portfolio Positions](/images/EN/M2/D4/EN-M2-D4-Currency-exchange-firstway.png)

A tab will open on the right (like when opening an order):

3. Select the target currency (for example, USD).

![IBKR Currency exchange from Portfolio Positions](/images/EN/M2/D4/EN-M2-D4-Currency-exchange-firstway-part2.png)

4. Enter the amount.

![IBKR Currency exchange from Portfolio Positions](/images/EN/M2/D4/EN-M2-D4-Currency-exchange-firstway-part3.png)

5. Review the commission in **"Preview"**.

![IBKR Currency exchange from Portfolio Positions](/images/EN/M2/D4/EN-M2-D4-Currency-exchange-firstway-part4.png)

6. Confirm the operation by clicking **"Submit"**.

### 2nd - Second method

1. From **Trading -> Convert Currency**

![IBKR Currency exchange from Order Ticket](/images/EN/M2/D4/EN-M2-D4-Currency-exchange-secondway.png)

2. Access the menu and perform the conversion similar to the previous step.

![IBKR Currency exchange from Order Ticket](/images/EN/M2/D4/EN-M2-D4-Currency-exchange-secondway-part2.png)
